# RecurCIV application metadata

The NRO's NACP title is `RecurCIV`; its author remains `msama`, the existing
Plume metadata. The utility description shown in the application is
`USB Keyboard and Controller Utility`. The installed `nacptool` and libnx NACP
structure do not provide a separate application-description field, so this
description is not advertised as NACP metadata.

`assets/recurciv-icon.jpg` is original RecurCIV artwork using the project's
Outfit font; its SIL Open Font License is in `assets/Outfit-OFL.txt`. The
original Plume icon and existing copyright and license notices are retained.
